# AWS Cloud Practitioner 対策ツール

AWS Certified Cloud Practitioner（CLF-C02）の試験対策ツールです。HTML 1つで動きます。外部のライブラリは使っていません。

## 使い方

- GitHub Pages で公開したページを、ブラウザで開きます（パソコンでもスマホでも使えます）。
- ダウンロードした `index.html` をブラウザで開いても動きます。
- 最初に「全体マップ」で受験日を入れると、残り日数と、11日間の計画の日付が出ます。

## 中身

| タブ | 内容 |
|---|---|
| 全体マップ | 試験の形、ドメインと配点、11日間の計画、成績 |
| ドメイン精読 | 4つのドメインの要点。表、引っかけ注意、覚え方 |
| サービス早見表 | 111サービス。検索、カテゴリ、★（最優先）で絞り込み |
| 用語集 | 略語と正式名、旧名と新名の対応 |
| クイズ・模試 | 115問。ドメイン別、総合模試（20問）、本番形式（65問・90分）、間違えた問題だけ、印つき |
| 罠の型 | 問題文の条件の読み方（めくるカード） |
| 似た者ペア | 紛らわしいサービスの見分け方 |
| つまずき総ざらい | よく間違える点の一覧 |
| 本番テクニック | 時間配分、読み方、当日の注意 |

## 注意

- 出題範囲は、AWS の公式の試験ガイド（改訂 1.3、2026年10月29日）に合わせています。サポートプランは2026年11月時点の公式ページで確認しました。最新の情報は公式で確認してください。
- 問題はすべてオリジナルです。本番の試験問題や、流出した問題は使っていません。
- 成績や間違えた問題の記録は、使っているブラウザにだけ保存されます。サーバーには送りません。パソコンとスマホでは共有されません。
- 合格を保証するものではありません。
